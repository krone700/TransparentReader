# 透明小说阅读器

一个 Windows 桌面小说阅读工具，最大特点是**背景完全透明**——文字直接浮在桌面上，一边看小说一边用别的软件。

## 怎么用

1. 双击 `透明小说阅读器.exe`（绿色免安装，不用装 Python）
2. 点窗口顶部的 **导入**（或按 `Ctrl+O`），选一个 `.txt` 小说
3. 打开后可以在 **目录** 里按章节跳转，章节名支持搜索
4. 觉得看得费劲就把窗口拖大，滚动条或滚轮翻页，`空格` 开关自动滚动

**导入一次就够了**：关掉程序再打开，会自动接着上次那本书、上次看到的章节和滚动位置，不用重新导入。想换书就点「目录」→「书架」，那里留着你读过的最近 30 本。

也可以先把 `.txt` 拖到 exe 图标上，或者直接把文件拖进窗口。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 背景透明 | 设置里的「背景」拉到 `0%`，窗口背景完全透明，只剩文字；0-100% 任意可调 |
| 章节支持 | 自动识别「第X章/第X回/序章/番外/Chapter N」等标题分章；识别不到时按字数自动分段 |
| 章节列表 | 目录面板列出全部章节，支持关键词搜索、点选跳转、上一章 / 下一章 |
| 导入小说 | 支持 `txt`（自动识别 UTF-8 / GBK / GB18030 / UTF-16 编码，乱码问题基本不会遇到）；可多选文件按文件名顺序合成一本 |
| 进度记忆 | 每本书的章节和滚动位置自动保存，下次打开原样接上 |
| 自动续读 | 启动时自动打开上次读的那本书并回到上次的位置，不必每次重新导入（`settings.json` 里的 `last_book`） |
| 书架 | 最近导入的 30 本书都留在「书架」页里，点一下即恢复 |
| 阅读调节 | 字体、字号、行距、左右留白、文字颜色（浅白/米黄/浅绿/浅粉/墨黑/自定义）、段首缩进、文字描边 |
| 一键预设 | 「纯文字」= 背景 0% 纯透明；「易读」= 16% 淡底，文字更清楚；「深色字」= 黑字，适合白色网页/文档 |
| 滚轮翻页 | 鼠标在窗口任意位置（正文、工具栏、空白处）滚动都能滚正文；滚到本章末尾继续往下滚会自动进入下一章，在章节开头继续往上滚会回到上一章末尾 |
| 自动续章 | 停在章末约 1.6 秒就自动进入下一章并回到顶部，不用手动点「下一章」；设置里可关 |
| 自动滚动 | 速度可调，滚到本章末尾自动进入下一章 |
| 鼠标穿透 | 开启后鼠标点击直接落到下面的软件上，不影响你操作，适合一边工作一边挂读 |
| 隐藏上下工具栏 | 设置里勾选「隐藏上下工具栏（只留正文）」，或按 `Alt+H`；勾选状态会记住，下次打开还是沉浸阅读。隐藏后鼠标移到窗口最顶部会浮出一排小按钮（`≡`目录 / `Aa`设置 / `－` / `✕`），鼠标移开自动消失 |
| 鼠标移开自动隐藏 | 默认开启：鼠标离开窗口，上下两条工具栏淡出消失，只剩正文；鼠标移回窗口，工具栏淡入出现（约 0.75 秒判定，避免手抖误触）。设置面板勾选「鼠标移开自动隐藏工具栏（移回就显示）」可关掉，右键菜单里也有同一开关。打开目录 / 设置面板、拖动窗口、缩放窗口时不收起 |
| 可缩到一条条文字 | 窗口最小尺寸只有「一行字」那么高（随字号/行距自动算，默认字号下约 150×86），可以拖成细细的一条挂在屏幕边上。窗口矮到放不下两条工具栏时（不足两行字），上下工具栏会自动让位、完全不占地方，改成鼠标移到顶部浮出迷你按钮（≡ Aa － ✕），移开自动消失；贴边 8 像素内按下即可拉伸改大小，正文上也能拖 |
| 置顶 | 窗口始终在最前面，默认开启 |

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+O` | 导入小说 |
| `F3` | 打开 / 关闭章节目录 |
| `F4` | 打开 / 关闭设置面板 |
| `空格` | 开关自动滚动 |
| `Alt+H` | 隐藏 / 显示工具栏（沉浸模式，正文区域会撑大） |
| `Alt+←` / `Alt+→` | 上一章 / 下一章 |
| `Ctrl+Alt+T` | **全局**开关鼠标穿透（穿透后就靠它恢复，任何窗口里按都有效）。若这个组合被别的软件占用，程序会自动改用 `Ctrl+Alt+R` / `Ctrl+Alt+U` / `Ctrl+Alt+J` / `Ctrl+Shift+T` / `Ctrl+Alt+9`，实际生效的那个会显示在「穿透」按钮的悬停提示里；全部被占用时，右键托盘图标也能恢复 |
| `Esc` | 退出穿透 / 关闭面板 |

## 设计上的几个取舍

- **背景 0% 时窗口仍然会占用鼠标**：所以透明阅读建议配合「穿透」一起用，这时窗口不抢鼠标，只做背景层；要操作时按一次热键恢复。
- **0% 透明并非“什么都不画”**：分层窗口里 alpha=0 的像素会让鼠标消息穿透到下层窗口（滚轮和点击都会落到浏览器或桌面上），所以 0% 时程序仍会画一层 alpha=1/255 的底色——肉眼看不出来，但窗口能正常接住鼠标，滚轮和点击都归它。
- **穿透状态下不能滚轮翻页**：因为鼠标事件全部透给下层软件了。这种场景用自动滚动，或先关掉穿透再翻。
- **滚轮滚到下面的软件了？** 先确认背景不是 0%？0% 这一层鼠标归属问题已在代码里修好（见上面 alpha=1 那条）。若仍偶尔滚到下层，那是 Windows 把滚轮发给「当前活动窗口」的规则：滚之前在小说正文里点一下，或在系统里打开「当我悬停在非活动窗口上时滚动它」（Win11：设置 → 蓝牙和其他设备 → 鼠标）。曾尝试全局鼠标钩子强行接管滚轮，但全局钩子挂在系统输入链上，回调稍有阻塞就会把整台机器的鼠标卡死，这个方案已废弃。
- **工具栏始终带一层半透明深色底片**，所以不管桌面是白底还是深色壁纸，按钮都看得清。
- **自动隐藏只藏工具栏，不动正文**：上下两条栏各自放在一个固定高度的容器里，隐藏时只把栏本身淡出，容器还占着原来的位置，所以正文不重排、字数不变化、你读到第几行还是第几行（实测隐藏前后正文区域尺寸完全一致）。这也是它和「隐藏工具栏（沉浸模式）」的区别——沉浸模式会把正文区域撑大、重新排版。
- **窗口最小尺寸是算出来的，不是写死的**：按当前字号 × 行距算出「一行字」需要多高，再把窗口内边距和正文上下留白加上去（默认字号下 ≈ 150×86）。换字号、调行距后最小值会跟着变，所以放大字号也不会出现「字被砍一半」。
- **窗口矮到装不下两条工具栏时，工具栏自动让位**：高度不足「两条栏 + 两行字」时（默认字号约 194 px），上下工具栏整个藏起来、不参与布局，正文直接铺满整个窗口，这样窄条窗口里也能看到两行字。改成鼠标移到窗口最上方时浮出一排迷你按钮（`≡`目录 / `Aa`设置 / `－`最小化 / `✕`关闭），移开就消失；也可以用右键菜单或快捷键（`Ctrl+O`、`F3`、`F4`、`Alt+←/→`）。把窗口拖大一点，正式工具栏自己回来。
- **小窗口也能拖着改大小**：贴边 8 像素以内按下就能拉伸（上下左右和四个角都算），而且在正文文字、滚动条上按下也照样生效——不用非去找那几条缝。右下角的缩放柄也照旧可用。
- **目录 / 设置是独立浮窗，不受主窗口大小限制**：点开后贴在主窗口右侧弹出（右边放不下就放左边），尺寸固定 320 / 340 宽、最高 640 高，主窗口缩成一条细线也能把设置完整摆开、内容还能上下滚动。浮窗可以按住空白处拖到任意位置（拖过之后就不再自动跟随主窗口），点右上角 ✕ 关闭；主窗口最小化 / 隐藏时浮窗一起收起。
- **读到章末自动进下一章**：滚到本章最后一行并停住约 1.6 秒，自动加载下一章、回到顶部；中途往上滚一下就取消。设置面板和右键菜单里都有「读到章末自动进入下一章」开关，关掉就恢复手动切章。
- 文字描边是自适应方向的：浅色字配黑边、深色字配白边，这样在深色壁纸和白色页面上都能读；但白字压白底终究偏淡，白色页面上请用预设「深色字」。
- **置顶会自动维持**：程序每 3 秒把窗口重新顶到最前，避免被浏览器、微信这类同样置顶的窗口压到下面——一旦被压住，你的滚轮和点击就都落到别的窗口上了。
- 如果程序意外退出，`%APPDATA%\TransparentNovelReader\crash.log` 里会留一份当时的调用栈，排查闪退直接看它。
- **书被移走或删掉了**：自动续读会失败，顶栏提示「上次的书找不到了：xxx.txt」，同时正文回到欢迎页，从「书架」里另选一本即可（书架里失效的条目也可以点「导入」重新加进来）。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `透明小说阅读器.exe` | 打包好的程序，双击即用 |
| `main.py` | 源码（Python 3 + PyQt5），想改功能就改这里，改完 `python main.py` 即可运行 |
| `app.ico` | 程序图标 |
| `测试小说.txt` | 用来演示分章效果的样例文本 |

配置和阅读进度保存在 `%APPDATA%\TransparentNovelReader\`（settings.json / progress.json / library.json），删掉这个文件夹就是恢复出厂设置。

## 从源码运行

```bash
pip install pyinstaller
python main.py
```

重新打包：

```bash
python -m PyInstaller --noconfirm --onefile --windowed --name "透明小说阅读器" --icon app.ico main.py
```
